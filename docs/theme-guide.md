# 水鱼文集 · 外观主题定制说明

水鱼文集的外观以**主题**为单位管理：内置主题 + 自定义主题。每套内置主题把配色、字体、字号、背景**打包**在一起，选一套即整体生效。所有外观配置按 NAS 账号独立保存，换账号登录互不影响。

---

## 一、在哪里设置

**设置页右下角的用户卡片**（头像 + 账号名）→ 点开右侧「外观」抽屉：

| 选项 | 说明 |
| --- | --- |
| 主题模式 | 跟随系统 / 浅色 / 深色 |
| 主题 | 点选主题卡片，立即预览 |
| 自定义主题 | 上传 `.js` 文件生成新主题，见第三节 |

抽屉里的改动**先预览、不落盘**：右下角会出现「保存 / 取消」，点 ✓ 才写入，点 ✕ 回到原样。中途切换设置子菜单、关掉抽屉都不会丢改动；带着未保存的改动离开设置页时会先问一句。

### 内置主题

| 主题 | 配色 | 字体 | 字号 | 背景 |
| --- | --- | --- | --- | --- |
| 纸墨（默认） | 湖蓝 | 系统字体 | 100% | 纯色 |
| 琥珀 | 琥珀棕 | 系统字体 | 100% | 淡彩 |
| 松绿 | 松绿 | 衬线字体 | 105% | 淡彩 |
| 紫罗兰 | 紫罗兰 | 圆体 | 100% | 淡彩 |
| 玫红 | 玫红 | 系统字体 | 100% | 淡彩 |

主题模式（浅色 / 深色）与主题相互独立：每套主题都自带深浅两套配色，切换模式不用重选主题。

## 二、自定义主题怎么写

自定义主题不再是一段脚本，而是**一行一条的声明**：只写想改的项，其余全部沿用内置外观。

```
主色: #1F6C9F
副色: #B45309
背景: https://example.com/bg.jpg
字体: 宋体
```

写进任意 `.js` 文件（如 `my-theme.js`）即可。三种写法都认：

```
主色: #1F6C9F
主色 = #1F6C9F
主色 #1F6C9F
```

`//` 或 `#` 开头的行是注释，可以随便写说明：

```
// 暖色阅读主题
主色: #8C5A2B
副色: #B45309
```

### 支持的键

| 键（中 / 英） | 作用 | 取值 |
| --- | --- | --- |
| `主色` / `accent` | 强调色：图标、链接、选中态、按钮 | 颜色，如 `#1F6C9F`、`rgb(31,108,159)` |
| `副色` / `accent2` | 次级强调（子菜单高亮条）+ 页面底色的淡彩 | 颜色 |
| `背景` / `bg` | 页面背景图；填颜色则直接当纸面色 | `https://…` 图片地址，或颜色 |
| `字体` / `font` | 正文字体 | 预设 `serif` / `round` / `mono` / `system`，或字体名如 `宋体` |
| `文字` / `ink` | 正文文字色 | 颜色 |
| `底色` / `paper` | 纸面底色（会盖过「副色」算出的淡彩） | 颜色 |
| `圆角` / `radius` | 卡片与控件圆角 | `0`–`40`（单位 px，自动换算大圆角） |

只写想改的项。比如只想要一支新主色，文件里就一行：

```
主色: #2F6B4F
```

### 生效规则

- 强调色的浅底、描边、深色模式下的高亮值，都会按主色自动算出来，不用手写一堆变量
- 副色会给页面底色带一点点色相（约 5%），比纯白/纯黑柔和
- 背景图铺在最底层并压一层纸色，正文与卡片保持可读
- 深浅色模式切换时会自动重算，不用为两套模式各写一份

### 与旧版脚本主题的差别

1.2.2 及更早的版本里，自定义主题是**可执行脚本**（`document.documentElement.style.setProperty(...)`）。为了让主题更好懂、也不再执行任意代码，1.2.3 起改为上面的声明式写法：

- 旧脚本**不会**再被执行，也不会报错，效果等同没有设置任何样式
- 需要旧效果时，把脚本里的 `--accent` 之类换算成对应键即可，绝大多数情况一两行就够
- 有把握想保留原脚本的，可以在「设置 → 管理员设置」之外自建样式表；应用本身不再提供脚本入口

### 限制

- 单个文件 ≤ **64 KB**（超出部分截断），最多 20 个自定义主题
- 主题名取自文件名（`my-theme.js` → 「my-theme」），重名自动加 `(2)` 后缀
- 悬停主题卡片右下角的 **✕** 可移除主题（保存后生效）

## 三、常见配方

**护眼米色 + 暖棕**

```
主色: #8C5A2B
副色: #B45309
底色: #F7F1E6
```

**衬线正文 + 深绿主色**

```
主色: #2F6B4F
字体: serif
```

**带一张固定背景图**

```
主色: #1F6C9F
背景: https://example.com/paper-texture.jpg
```

**更大的圆角**

```
圆角: 12
```

## 四、排查

1. 改完没反应：确认右下角点了 ✓ 保存；保存条没出现说明文件内容没被识别（检查是不是漏了冒号）
2. 某一行写错：该行会被跳过，其余行照常生效，不会整份失效
3. 想回到内置外观：抽屉里选「纸墨」，保存即可；移除自定义主题会清掉它带来的全部样式
4. 主题文件在哪：外观配置保存在应用数据目录的 `users/<你的账号>/config.json`，卸载应用会一并清除
