# 水鱼文集 · 外观主题定制说明

水鱼文集的外观以**主题**为单位管理：内置主题 + 自定义主题。每套内置主题把配色、字体、字号、背景**打包**在一起，选一套即整体生效。所有外观配置按 NAS 账号独立保存，换账号登录互不影响。

---

## 一、在哪里设置

**设置页左下角的用户卡片**（头像 + 账号名）→ 点开左侧滑出的「外观」抽屉：

| 选项 | 说明 |
| --- | --- |
| 主题模式 | 跟随系统 / 浅色 / 深色 |
| 主题 | 点选主题卡片，立即生效并保存 |
| 自定义主题 | 上传 `.js` 文件生成新主题，支持简单 / 复杂两种写法 |

改动**即时保存**，不需要手动确认；保存失败会弹提示并自动回到上一次保存的外观。

### 内置主题

| 主题 | 配色 | 字体 | 字号 | 背景 |
| --- | --- | --- | --- | --- |
| 纸墨（默认） | 湖蓝 | 系统字体 | 100% | 纯色 |
| 琥珀 | 琥珀棕 | 系统字体 | 100% | 淡彩 |
| 松绿 | 松绿 | 衬线字体 | 105% | 淡彩 |
| 紫罗兰 | 紫罗兰 | 圆体 | 100% | 淡彩 |
| 玫红 | 玫红 | 系统字体 | 100% | 淡彩 |

主题模式（浅色 / 深色）与主题相互独立：每套主题都自带深浅两套配色，切换模式不用重选主题。

## 二、自定义主题：简单写法

一行一条声明，只写想改的项，其余全部沿用内置外观。

```
主色: #1F6C9F
副色: #B45309
背景: https://example.com/bg.jpg
字体: 宋体
```

写进任意 `.js` 文件（如 `my-theme.js`）即可。三种写法都认：

```
主色: #1F6C9F
主色 = #1F6C9F
主色 #1F6C9F
```

`//` 或 `#` 开头的行是注释，可以随便写说明：

```
// 暖色阅读主题
主色: #8C5A2B
副色: #B45309
```

### 支持的键

| 键（中 / 英） | 作用 | 取值 |
| --- | --- | --- |
| `主色` / `accent` | 强调色：图标、链接、选中态、按钮 | 颜色，如 `#1F6C9F`、`rgb(31,108,159)` |
| `副色` / `accent2` | 次级强调（子菜单高亮条）+ 页面底色的淡彩 | 颜色 |
| `背景` / `bg` | 页面背景图；填颜色则直接当纸面色 | `https://…` 图片地址，或颜色 |
| `字体` / `font` | 正文字体 | 预设 `serif` / `round` / `mono` / `system`，或字体名如 `宋体` |
| `文字` / `ink` | 正文文字色 | 颜色 |
| `底色` / `paper` | 纸面底色（会盖过「副色」算出的淡彩） | 颜色 |
| `圆角` / `radius` | 卡片与控件圆角 | `0`–`40`（单位 px，自动换算大圆角） |

只写想改的项。比如只想要一支新主色，文件里就一行：

```
主色: #2F6B4F
```

## 三、自定义主题：复杂写法

需要调整**界面、动画、图标**时，把主题写成一段脚本：文件里定义 `function theme(api)`，应用检测到这个函数就按复杂模式执行。

```js
function theme(api) {
  // 1. 调 CSS 变量
  api.setVar('--accent', '#7C5CFF');
  api.setVar('--r', '14px');          // 圆角

  // 2. 注入样式：界面微调、动画都写在这里
  api.css(`
    .card { transition: transform .25s ease, box-shadow .25s ease; }
    .card:hover { transform: translateY(-2px); }   /* 卡片悬浮动效 */
    .page-title { letter-spacing: .02em; }
    .theme-card { animation: apFadeUp .3s ease both; }
    @keyframes apFadeUp { from { opacity: 0; transform: translateY(6px); } }
  `);

  // 3. 换图标（可选）：SVG path 覆盖内置图标，颜色跟随 currentColor
  api.icon('rocket', '<path d="M12 3l7 7-9 11H4v-6z"/>');
}
```

### API 一览

| 调用 | 作用 |
| --- | --- |
| `api.setVar(name, value)` | 设置根元素 CSS 变量（`name` 必须以 `--` 开头） |
| `api.css(text)` | 注入一段 `<style>`，切换主题时自动移除 |
| `api.icon(name, svg)` | 覆盖内置图标；`svg` 为 SVG 内部图形（path 等），也接受完整 `<svg>` |
| `api.el` | 根元素（`document.documentElement`），可自行查询任何节点 |
| `api.dark` | 当前是否深色模式（实时读取，可做分支配色） |
| `api.vars(name)` | 读取某个 CSS 变量的当前值 |

### 生效与清理规则

- 每次应用主题（登录、切换主题、深浅色变化）都会**先清理再执行**：变量回退、注入的 `<style>` 移除、图标还原，因此复杂主题每次都从干净状态运行，不会叠加
- 复杂主题执行出错时会在控制台打印原因，界面回退到内置外观，不影响使用
- 主题只在你自己的浏览器里运行，随外观配置保存在你的账号下

## 四、常见配方

**护眼米色 + 暖棕**（简单）

```
主色: #8C5A2B
副色: #B45309
底色: #F7F1E6
```

**衬线正文 + 深绿主色**（简单）

```
主色: #2F6B4F
字体: serif
```

**卡片悬浮动效**（复杂）

```js
function theme(api) {
  api.css(`
    .card, .record { transition: transform .2s ease, box-shadow .2s ease; }
    .card:hover, .record:hover { transform: translateY(-3px); }
  `);
}
```

## 五、排查

1. 改完没反应：设置改动即时保存，若主题没有生效，说明文件内容没被识别——简单写法检查冒号，复杂写法确认定义了 `function theme(api)`
2. 某一行写错（简单写法）：该行会被跳过，其余行照常生效，不会整份失效
3. 想回到内置外观：抽屉里选「纸墨」即可；移除自定义主题会清掉它带来的全部样式与图标
4. 主题文件在哪：外观配置保存在应用数据目录的 `users/<你的账号>/config.json`，卸载应用会一并清除

### 限制

- 单个文件 ≤ **64 KB**（超出部分截断），最多 20 个自定义主题
- 主题名取自文件名（`my-theme.js` → 「my-theme」），重名自动加 `(2)` 后缀
- 悬停主题卡片右下角的 **✕** 可移除主题
